# Solitario

Recreación del clásico juego de cartas Solitario, hecha en Python con Pygame.

## Qué hace

- Implementa la lógica completa del juego (reparto, movimientos válidos, victoria).
- Gestiona el estado de la partida con estructuras de datos propias (pilas y listas) para llevar el historial de movimientos y poder deshacer jugadas.
- Interfaz gráfica con imágenes y música propias.

## Tecnología

Python, Pygame.

## Cómo ejecutarlo

```bash
pip install pygame
python Solitario.py
```

También se puede generar un ejecutable independiente con PyInstaller usando `Solitario.spec`.
